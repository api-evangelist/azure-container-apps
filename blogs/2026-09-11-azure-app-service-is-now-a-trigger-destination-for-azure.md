Azure Managed Connectors, currently in public preview, now lets you choose Azure App Service as a trigger destination . Connector events can be delivered directly to applications running on App Service, including ASP.NET Core, Java, Node.js, and Python applications. This is a new capability in the Managed Connectors public preview .
